[size=4][b]How it works[/b][/size]
[list]
[*]Speeds up the actual opening animation for doors and containers, so it plays instantly instead of the usual lengthy animation. Yes, I like Morrowind, how did you guess ?[/*]
[*]Only touches doors that actually load into a new cell.[/*]
[*]Optionally also shortens several Skyrim.ini loading screen fade durations[/*]
[*]Settings accessible in ini file next to the plugin[/*]
[*][color=#008000][b]Safe to install, update, or remove at any point in a playthrough.[/b][/color][/*]
[/list]

[size=4][b]Installation[/b][/size]
Install with your mod manager like any other SKSE plugin. Requires:
[list]
[*][url=https://skse.silverlock.org/]SKSE64[/url][/*]
[*][url=https://www.nexusmods.com/skyrimspecialedition/mods/32444]Address Library for SKSE Plugins[/url][/*]
[/list]
Compatible with both Skyrim SE/AE 1.6.1170 and 1.7.104, thanks to greater minds than my own.

[b][size=4]Configuration[/size][/b]
[font=Courier New]SnapOpen.ini[/font] (located next to the plugin, under SKSE/Plugins) has two settings :
[list]
[*][font=Courier New]bOverrideFadeSettings[/font] : also shortens the Skyrim.ini fade/loading durations mentioned above. Set to 0 to leave your own Skyrim.ini alone. On by default.[/*]
[*][font=Courier New]bExperimentalNPCDoors[/font] : also speeds up doors when NPCs use them, not just you. Off by default for the time being, I need to test it a bit more to be sure it doesn't break anything.[/*]
[/list]
[b][size=4]But... why?[/size][/b]
I like doors to be fast, and I don't like staring at long-winded animations. I also like looting quickly but don't like Quickloot. Hence this.
The existing solutions for this (see Credits) are mesh/behavior edits, which work but can create conflicts and require some patching. This plugin should handle all doors and containers without any of that.

[size=4][b]Known issues and limitations[/b][/size]
[list]
[*][size=3]Might not play well with any mod that unpauses container menus (like [url=https://www.nexusmods.com/skyrimspecialedition/mods/27859]Skyrim Souls[/url])[/size][/*]
[*][size=3]Not extensively tested with [url=https://www.nexusmods.com/skyrimspecialedition/mods/120075]Quickloot[/url] as I don't use that[/size][/*]
[/list]
